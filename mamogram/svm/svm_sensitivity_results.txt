WHY: C controls the regularization strength (inverse relationship).
- Small C → Strong regularization → Soft margin → More training errors allowed
  → Simpler model → Better generalization → More support vectors
- Large C → Weak regularization → Hard margin → Fewer training errors
  → Complex model → Risk of overfitting → Fewer support vectors

This is typically the MOST IMPORTANT parameter for SVM performance.
Notice how support vectors decrease as C increases (model gets more strict).

WHY: Kernel choice determines how data is transformed into higher dimensions.
- linear: No transformation, creates linear decision boundary. Fastest, good for
  linearly separable data. Can underfit non-linear patterns.
- rbf: Radial Basis Function, most versatile. Creates smooth, non-linear boundaries.
  Usually best default choice for unknown data patterns.
- poly: Polynomial kernel, creates polynomial decision boundaries. Good for
  modeling feature interactions. Can be slow and numerically unstable.
- sigmoid: Similar to neural network activation. Less commonly used, can be
  unstable. Rarely the best choice.

Kernel choice is CRITICAL - wrong kernel = poor performance regardless of tuning.

================================================================================
KEY INSIGHTS FOR SVM:
================================================================================

1. FEATURE SCALING: SVM is extremely sensitive to feature scaling. Always use
   StandardScaler or similar before training.

2. SUPPORT VECTORS: The number of support vectors indicates model complexity.
   More support vectors = more complex decision boundary.

3. OVERFITTING CHECK: Compare train vs test accuracy. Large gap = overfitting.
   If overfitting: decrease C (stronger regularization) or use simpler kernel.

4. COMPUTATIONAL COST: RBF and poly kernels are slower than linear. Training time
   scales poorly with dataset size (roughly O(n^2) to O(n^3)).

5. HYPERPARAMETER TUNING ORDER:
   a) First: Choose kernel (try RBF as default)
   b) Second: Tune C (most impactful for performance)
   c) Third: If using RBF/poly, tune gamma (not done in this analysis)
